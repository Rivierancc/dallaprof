# Dalla_prof

Crea app totem fast food kiosk mode.

Schermata 1: Scelta DOVE MANGI? [Qui / Asporto] 

Schermata 2: Menu a categorie con foto grandi, pulsanti enormi.

Carrello a destra sempre visibile.

Checkout: riepilogo + pagamento finto (pulsante Paga).

Alla fine genera numero ordine a 2 cifre grande.

Pannello cucina separato su /cucina che mostra ordini in arrivo in tempo reale con suono.

Pannello display cliente su /display che mostra "In preparazione / Pronto".

Usa Next.js, Supabase Realtime, Tailwind. Ottimizzato per touch 1080x1920 verticale.
